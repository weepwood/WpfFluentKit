# WpfFluentKit

一套面向 Windows 桌面工具软件的 Fluent 风格 WPF UI 组件库与交互式 Gallery 示例。

基于 **.NET 8 / WPF / WPF UI / WPF UI Violeta**。本项目的组件、样式和示例独立实现；参考 BetterGI 的桌面工具界面组织方式，不复制 BetterGI 的 GPL-3.0 代码。

> 代码与示例正在初始化。后续提交包含组件库、可运行的 Gallery Demo、Windows GitHub Actions 打包和说明。

- UI 基础：[lepoco/wpfui](https://github.com/lepoco/wpfui)
- 扩展组件：[emako/wpfui.violeta](https://github.com/emako/wpfui.violeta)
- 视觉参考：[babalae/better-genshin-impact](https://github.com/babalae/better-genshin-impact)
